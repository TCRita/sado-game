# sado-game
# 茶の湯 お点前稽古

裏千家「風炉 薄茶 平点前」を、ブラウザで練習できる学習ゲームです。
お点前の手順と所作を、ゲーム感覚で覚えることを目指しています。

🔗 **遊ぶ：https://tea-ceremoy.netlify.app**

## できること

| モード | 内容 |
| --- | --- |
| 図鑑 | お点前に出てくる道具を、畳の上で見て、名前や使い方を調べられます |
| ガイド付き練習 | 次にすることを説明つきで案内します。道具をクリックして進めます |
| 本番 | 説明なしで、自分で次の動作を考えて進めます |
| 三択 | 所作や決まりごとを、三択のクイズで確認します |
| 手順一覧 | すべての手順を表で見られます |
| お道具の美術館 | 道具をくわしく見られる別ページです |

- お点前は、お菓子を出すところから、点前、飾り残し、道具を持ち帰るところまでを通して練習できます。
- 「茶筅で点てる」の手順は、トントン → シャカシャカ → 泡を整える → 「の」の字の、ミニゲームです。
- 畳の絵は、上から見た画面と、亭主の目線の画面を切り替えられます。

## このゲームについて

- 学習用の個人制作です。公式の教材ではありません。
- 手順や寸法は、習った内容をもとに作っています。まちがいや、流派・先生による違いがあるかもしれません。
- 道具や畳の絵は、すべてコードで描いたドット絵です（画像ファイルは使っていません）。

## 自分のパソコンで動かす

ビルドもインストールも要りません。`index.html` をブラウザで開くだけで動きます。

## ファイルの構成

```
index.html            ゲーム本体の画面
museum.html           お道具の美術館
data/
  tools.js            道具の一覧
  quiz.js             三択の問題集
  temae/              お点前の手順（1ファイル＝1つのお点前）
js/                   プログラム
css/style.css         見た目
```

新しいお点前を足すときは、`data/temae/` に手順のファイルを作って、`index.html` に1行足します。
手順は、読みやすい書き方のデータで書いてあり、プログラムを書き換えなくても編集できます。

## 使っているもの

HTML・CSS・JavaScript だけ（ライブラリや外部サービスは使っていません）。
