茶の湯 お点前稽古（裏千家）  使い方
=====================================

■ 開き方
  1. Finder で「書類」→「sado-game」フォルダを開く
  2. index.html をダブルクリック（ブラウザで開きます）
     ※ Safari / Chrome / Edge / Firefox どれでも動きます。インターネット接続は不要です。
  3. ファイルを書き換えたら、ブラウザで再読み込み（⌘ + R）すると反映されます。
  ※ mihon.html は、道具を重ねた絵の見本ページです（ゲームとは別）。


■ 画面
  ・大きい画面と、右下の小窓の2つがあります。
      上から      … 畳を真上から見た図。亭主が下、向こう（風炉先）が上。
      亭主の目線  … 点前座に座って、少し見下ろした景色。手元を寄って見るので細かく描いてあります。
    2つの画面は同じ状態を映しているので、片方で道具が動けばもう片方でも動きます。
    小窓をクリック（または右上のボタン）で、大きい画面と入れ替わります。
  ・どちらの画面の道具もクリックできます。

■ モード
  ・図鑑            … 道具をクリックすると、名前・読み仮名・役割・扱い方が出ます。
  ・ガイド付き練習  … 画面上部に手順名、右に説明が出ます。正しい道具をクリックすると次へ進みます。
                      間違えるとヒントが出ます。「次は何をしますか？」で答えの道具が光ります。
  ・本番            … 手順名もヒントも出ません。最後に間違えた回数とかかった時間が出ます。
  ・三択            … 所作や決まりごとの三択問題を、くり返し解きます。間違えた問題は少しあとにもう一度出ます。
                      「苦手な問題だけ」を選ぶと、間違えた問題だけを練習できます。
  ・手順一覧        … お点前データの中身を表で確認できます。書き間違いがあればここに表示されます。


■ フォルダの中身
  index.html                      … 起動するファイル
  data/tools.js                   … 道具の一覧（名前・説明・図鑑での位置・写真のパス）
  data/temae/furo_usucha_hira.js  … 風炉 薄茶 平点前の手順（運び出しは方法書から、本体は叩き台）
  data/quiz.js                    … 三択の問題集（三択モードで使う）
  data/museum.js                  … お道具の美術館の説明
  assets/                         … 写真を置く場所（最初は空）
  js/                             … プログラム本体（ふつうは触らなくて大丈夫）
  css/                            … 見た目の設定


■ データの書き方のコツ
  ・データファイルはテキストエディタで開けます（VS Code などだと色分けされて書きやすいです）。
  ・先頭の registerTools( / registerTemae( と、最後の ); は消さないでください。
  ・文字は "（半角のダブルクォート）" で囲みます。項目と項目の間には , （半角カンマ）。
  ・// から行の終わりまではメモになります。稽古で気づいたことを書き残せます。
  ・最後の項目の後ろにカンマが残っていても大丈夫です。
  ・書き間違えたときは、画面上部に「どのファイルの何行目あたりか」が赤く表示されます。


■ 手順を直す・足す（data/temae/furo_usucha_hira.js）
  1つの手順はこの形です：
      {
        "id": "s05",
        "name": "帛紗を腰から取り、捌く",
        "view": "host",              ← 大きく映す画面（"top" 上から ／ "host" 亭主の目線）
        "description": "説明文",
        "target": "fukusa",          ← クリックする道具の id（tools.js の id）
        "moveTo": "te_fukusa",       ← （なくてもよい）その道具の移動先
        "hint": "ヒント文"
      },
  ・手順を足すときは { から }, までをまるごとコピーして、好きな位置に貼り付けて書き換えます。
  ・id は他と重ならなければ何でも構いません（例："s05-2"）。
  ・場所をクリックさせたいときは "target": "place:sadouguchi" のように書きます。
  ・ほかの道具も一緒に動かしたい、茶碗に湯を入れたい、などは "effects" を使います
    （書き方はファイル先頭の説明を見てください）。

  ・所作や決まりごとを答えさせたいときは、三択の手順にします：
      {
        "id": "kashi-04", "type": "quiz",
        "name": "お菓子を出したあとの礼",
        "question": "このときの礼は？",
        "choices": ["真の礼（45度）", "行の礼（30度）", "草の礼（15度）"],
        "answer": "真の礼（45度）",          ← choices のどれかと同じ文字にする
        "explain": "お菓子を出す時は真の礼をします。"
      },
    選択肢は毎回並べ替えて出ます。ここに書いた三択は、三択モードにも自動で出ます。
  ・「お点前開始！」のように文字を大きく出したいときは：
      { "id": "kaishi", "type": "banner", "text": "お点前開始！" },
  ・最後の画面の文字は、お点前データの "finishTitle"（お点前おわり！）と "finishMessage"（よし！）で変えられます。


■ 道具を重ねる（中に入れる・上に乗せる）
  置き場所は、場所の名前のほかに「どの道具の中／上か」でも書けます。
      { "on": "chawan", "how": "in" }    … 茶碗の中に入れる
      { "on": "natsume", "how": "on" }   … 棗の上に乗せる
  乗っている先の道具が動くと、乗っている道具も一緒に動きます
  （例：茶碗を運ぶと、仕組んだ茶巾・茶筅・茶杓も一緒に運ばれます）。
  少しずらしたいときは "dx"（右へ）、"dy"（下＝手前へ）、"dz"（高く）を足します。


■ 道具の位置を直す
  ・図鑑での位置    … data/tools.js の "pos": { "x": 横, "y": 縦 }
  ・お点前での位置  … data/temae/…js の "places"（場所）と "setup"（はじめの配置）
  ・上からの画面は 横320 × 縦462 の点です。1点＝1cm（京間の六畳間：畳1枚 191cm × 95.5cm）。
    左上が (0, 0)。x を増やすと右へ、y を増やすと下（手前）へ。
    畳はすべて同じ 96 × 192 の点です（95.5cm は点にできないので 96 にそろえています）。
    だいたいの目安：点前畳 x=18〜114, y=18〜210（半畳の線 y=114）／ 風炉 x=45, y=74 ／ 水指 x=92, y=67
                    踏込畳 x=18〜114, y=210〜402 ／ 客畳 x=114 より右 ／ 茶道口 y=402 より下
  ・畳の並び（どの畳がどこにあるか）は js/pixel-art.js の ROOM に書いてあります。
  ・亭主の目線の画面に映す範囲は、お点前データの "hostCamera" で変えられます。


■ 写真に差し替える
  ・assets/ に、tools.js の "image" に書いた名前で写真を置くだけです（上からの画面に使われます）。
    例：棗なら assets/natsume.png（.jpg にしたいときは "image" の方も .jpg に書き換え）
  ・写真があればその写真、なければドット絵が表示されます。
  ・表示の大きさを変えたいときは、その道具に "size": { "w": 24, "h": 24 } を足します。
  ・真上から撮った、背景を透明にした PNG がいちばんきれいに見えます（亭主が下になる向きで）。


■ 別のお点前を足す（炉・濃茶など）
  1. data/temae/furo_usucha_hira.js をコピーして、名前を変える（例：ro_usucha_hira.js）
  2. 中の "id" と "title" を書き換え、手順を直す
  3. index.html の「お点前の手順」の行の下に、次の1行を足す
       <script src="data/temae/ro_usucha_hira.js" data-temae></script>
  4. 画面右上の「お点前：」で選べるようになります
  ※ 炉など、新しい道具が必要なら data/tools.js に道具を足します（絵がない道具は仮の四角で出ます）。


■ 注意
  ・手順の叩き台は大まかな流れです。「要確認」と書いた所は、稽古ノートや先生の教えで直してください。
  ・道具の位置も仮置きです。
